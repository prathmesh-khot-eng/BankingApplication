# 🏦 Banking Services Application

A simple **console-based Banking Services Application** developed using **Core Java**. This mini project was created to practice fundamental Java programming concepts and understand how they can be combined to build a menu-driven application.

## 📌 Features

* 🔐 PIN-based user authentication
* 💰 Deposit money
* 💸 Withdraw money
* 📊 Check bank balance
* 🔑 Display current PIN
* 🚪 Exit banking services
* ⚠️ Basic input validation
* 🖥️ Menu-driven console interface

## 🛠️ Technologies Used

* **Core Java**

* **Loops**
* **String Handling**

## ⚙️ How the Application Works

1. The application starts with a banking services menu.
2. The user enters the PIN.
3. The entered PIN is compared with the predefined PIN.
4. After successful authentication, the user can select:

   * Withdrawal
   * Deposit
   * Check Bank Balance
   * PIN
   * Exit
5. The application continues running until the user selects **Exit**.

The application uses a `while` loop to repeatedly display the banking menu after successful PIN verification.
